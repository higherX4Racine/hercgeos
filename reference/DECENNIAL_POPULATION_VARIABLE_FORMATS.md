# Formats for decennial census variables of overall population.

A tibble with formatting data about the population variable for each
decennial census

## Usage

``` r
DECENNIAL_POPULATION_VARIABLE_FORMATS
```

## Format

### `DECENNIAL_POPULATION_VARIABLE_FORMATS` A data frame with 3 rows

and 4 columns:

- Year:

  Decadal years, e.g. 2010, 2020

- Group:

  The table of data that the variables are found in.

- Separator:

  The character, if any, that goes between the group name and the
  variable number

- Suffix:

  The suffix, if any, that goes on the end of a variable name
