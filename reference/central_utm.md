# Find the median UTM Zone from a vector of longitudes.

Find the median UTM Zone from a vector of longitudes.

## Usage

``` r
central_utm(.longitudes)
```

## Arguments

- .longitudes:

  one or more decimal longitudes

## Value

a single integer code for one UTM Zone
